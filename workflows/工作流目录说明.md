## 同步到 ComfyUI

在**金帧仓库根目录**执行：

```powershell
.\install\sync_to_comfyui.ps1
```

若 ComfyUI 不在默认路径，请指定：

```powershell
.\install\sync_to_comfyui.ps1 -ComfyRoot "你的路径\ComfyUI"
```

## 恢复备份

若您手上有历史 JSON 备份，将文件复制回 `workflows\` 下同名路径后，再次运行 `sync_to_comfyui.ps1` 即可。
