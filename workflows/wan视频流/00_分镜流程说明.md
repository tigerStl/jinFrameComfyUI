# wan视频流 · 分镜关键帧 + 短视频拼接

> 8GB 显存推荐：**不要**在一段 Wan I2V 里做完整转身；用 **FLUX/SDXL 出多张关键帧** → **Wan 短片段** → **ffmpeg 拼接**。

## 目录（ComfyUI 侧栏）

工作流放在：

`ComfyUI/user/default/workflows/wan视频流/`

ComfyUI 的「文件夹」= 该路径下的**子目录名**，不是画布里的分组。

## 推荐流程（三步）

```mermaid
flowchart LR
  A[定妆 reference] --> B[01 FLUX 关键帧链]
  B --> C[kf_01 kf_02 kf_03]
  C --> D[03 首尾帧补间 或 02 稳态片段]
  D --> E[seg_A seg_B ...]
  E --> F[concat_segments.ps1]
  F --> G[final.mp4]
```

### 1. 关键帧（静图）

| 工作流 | 作用 |
|--------|------|
| `01_FLUX_关键帧_三连图.json` | 定妆图 I2I 链：正面 → 微转 → 侧身，一次 Queue 出 3 张 |
| （可选）`日系惊悚_场景/` 下 SDXL/Flux 场景 + `Flux_I2I_定妆照参考` | 空镜 + 人景融合，手动导出多张关键帧 |

**输出**：`ComfyUI/output/keyframe/kf_01.png` … `kf_03.png`  
**复制到**：`ComfyUI/input/keyframe/`（Wan LoadImage 默认路径）

可继续加 `kf_04.png`：复制 `01` 工作流，把上一段 SaveImage 的图接到下一段 VAEEncode。

### 2. 短视频片段（Wan）

| 工作流 | 方式 | 适用 |
|--------|------|------|
| `03_Wan_首尾帧_补间_GGUF.json` | **WanFirstLastFrame**：首帧 kf_01 + 尾帧 kf_02 | **相邻关键帧之间**的过渡（推荐转身分镜） |
| `02_Wan_片段_A/B/C_*.json` | **Wan I2V 稳态**：仅首帧 + 微动 prompt | 预览、空镜微动、或首尾帧失败时的兜底 |

**参数（8GB）**：768×432，`length=49`（约 3s @16fps），Lightning LoRA **0.6**，`--lowvram`。

**提示词**：写「向目标姿态缓慢过渡」，**不要**写 spin / turn around / walk away 等大动作。

每段 **Queue 一次** → `output/video/wan_storyboard/seg_A_00001.mp4` 等。

### 3. 拼接

在 `wan视频流` 目录运行：

```powershell
.\concat_segments.ps1 -Segments seg_A_00001.mp4,seg_B_00001.mp4 -Out final_storyboard.mp4
```

或手动 ffmpeg concat（见脚本内注释）。

## 转身分镜示例

| 镜号 | 关键帧 | Wan |
|------|--------|-----|
| 1 | kf_01 正面 | 03：kf_01 → kf_02 |
| 2 | kf_02 25° | 03：kf_02 → kf_03 |
| 3 | kf_03 侧身 | 02_C：kf_03 稳态 1–2 秒（可选） |

## 与 FLUX / SDXL / XDSL 的分工

- **FLUX**：人物一致性、渐进 I2I 出关键帧（本目录 `01`）
- **SDXL**：国人肖像、惊悚场景空镜（`SDXL_AWPortraitXL`、`日系惊悚_场景`）
- **Wan**：只负责 **帧间运动**，不负责「一张图里转 180°」

## 首尾帧 GGUF 说明

`03` 由官方 `video_wan2_2_14B_flf2v.json` 自动替换为 **UnetLoaderGGUF + CLIPLoaderGGUF**（与 `Wan22_I2V_GGUF_8GB` 同套模型）。

若 Queue 报错：先用 `02` 稳态片段；或安装 fp8 首尾帧模型后改用官方未 patch 模板。
