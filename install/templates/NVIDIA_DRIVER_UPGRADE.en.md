## Why upgrade?

ComfyUI **v0.21+** on RTX 30/40 (e.g. **3050**) needs **PyTorch cu130 (CUDA 13)**.  
On Windows, CUDA 13 requires **NVIDIA driver 580.0 or newer**.

Typical errors when the driver is too old:

- `torch 2.10.0+cu130` installed but `torch.cuda.is_available() is False`
- `cudaErrorNotSupported` / `likely using older driver`

**Re-installing torch via pip will not fix this. Upgrade the driver and reboot first.**

RTX 50 series (e.g. 5060) uses cu128 nightly; driver **570.0+** recommended.

## Manual upgrade (we do not auto-install drivers)

1. Open https://www.nvidia.com/Download/index.aspx
2. Select your GPU (e.g. GeForce RTX 3050) -> **Windows 10/11 64-bit** -> **Game Ready Driver**
3. Download and run the installer  
   - Install **Graphics Driver / Display Driver** only  
   - **Uncheck NVIDIA App** (avoids chrome_elf.dll / Access is denied)
4. **Reboot**
5. Verify:

   ```powershell
   nvidia-smi
   ```

   Driver Version must be **>= {{MIN_VERSION}}**; for RTX 3050 / cu130, CUDA Version should show **13.x**

6. Continue:

   ```powershell
   cd <repo-root>
   .\install\ensure_nvidia_driver.ps1
   .\install\setup_comfyui.ps1 -ComfyRoot "<ComfyUI path>"
   ```

## Troubleshooting

| Symptom | Action |
|---------|--------|
| GPU is lost | Reboot, then nvidia-smi |
| chrome_elf.dll / Access is denied | Uncheck NVIDIA App; driver only |
| Remote Desktop | OK if nvidia-smi is healthy |
