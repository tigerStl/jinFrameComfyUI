金帧 AI 视频平台 · 一键安装程序

================================

English: README.en.md (Quick start section 0)

使用方式

--------

1. 在 jinFrameComfyUI 仓库根目录双击：一键安装.bat

2. 或直接运行：allInOneInstall\一键安装.exe



可选参数

--------

  --install-root=D:                    安装盘（ComfyUI -> D:\ComfyUI\ComfyUI）

  --comfy-root=D:\ComfyUI\ComfyUI      仅指定 ComfyUI 路径



首次运行会列出各磁盘剩余空间，并默认选择非 C 盘。

配置会保存到仓库根目录 jinframe_install_paths.json（已 gitignore）。



说明

----

- 自动检查 Git、Python、Node.js

- 按 COMFYUI.lock.json 安装 ComfyUI v0.21.1 与必需节点

- 安装金帧助手并同步工作流

- 大模型权重需另见 MODELS.md 或助手内下载
